# Laravel Todo App

## Tech Stack
|Stack          |Language/Framework|
|:--------------|:-----------------|
|Frontend       |Laravel           |
|Backend        |React Vite        |
|Storage        |SQLite - DB upgrade to Postgres coming soon|


## How to Run
1. Fork the repo `https://github.com/WayneCarlG/todo-app.git`
2. Clone the repo with your username
3. `cd todo-app`
4. Run `php artisan serve`
5. Congratulations! Your Application is up and running

## Using The Application
1. Logon to `http://localhost:8000/register` to create an account
2. After succesful entry of credentials, you will be redirected to login, complete the auth cycle
3. Your task dashboard is up and running
